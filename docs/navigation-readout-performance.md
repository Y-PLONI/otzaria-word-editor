# קריאות ניווט וסימני פסקה

## ניווט

`readNavOutline` קורא metadata של כלל הבלוקים ב־500 בכל בקשה, עד 25,000,
ושומר את מיקומם המקורי. טקסט מלא מתבקש רק למזהי הכותרות, בבקשות מסוננות.
תוצאת הניווט נשמרת לפי Document API וגרסתו; תזוזת סמן משתמשת במפת המיקומים.
שינוי גרסה במהלך הדפדוף או בין metadata לטקסט פוסל את התוצאה. כשל אינו
מחליף רשימה תקינה ב״אין כותרות״; סוף הסריקה החסום מסומן כניווט חלקי.

## ¶

עמודים שנחתכים עם אזור התצוגה, בתוספת 400px מכל צד, מספקים את חלון הקריאה.
`painted-lines` מזהה סופי פסקאות גוף לפי מזהה מקור וטווח מצויר, ומדלג על
fragment שממשיך בעמוד הבא. רק הפסקאות האלה מתבקשות מ־`blocks.list`, עם
`nodeIds` ו־`nodeTypes: ['paragraph']`; הטקסט נשמר במטמון חסום של 512 בלוקים.

המזהה נקשר לטקסט הקנוני של אותה פסקה. עבור fragment אחרון שממשיך מעמוד קודם
נבדקת התאמת סיומת; טקסט זהה בפסקאות שונות אינו מחליף זהות. פסקה ריקה משתמשת
ב־placeholder המצויר שלה. הטבלאות וכותרות העמוד אינן פסקאות גוף זכאיות.

המיפוי נבדק מול SuperDoc 2.23 דרך `file://`, כולל פסקה חוצה עמוד, פסקה ריקה
וטבלה. הוא נשאר בקורא ה־DOM שכבר קיים במאגר. כאשר המיפוי חסר/לא תקין,
משתמשים בשני הרצפים המלאים של ה־fallback; אין סינון של צד אחד בלבד.
זהו מסלול תאימות יקר יותר, ולא שיפור ביצועים מובטח במבנה DOM לא מוכר.

אין בחוזה `onUpdate` הציבורי רשימת מזהי בלוקים שהשתנו המוכחת כאן לכל
עריכה/סגנון/Undo/Redo. לכן הפסילה היא ברמת גרסת המסמך; אין ניחוש של עדכון
מצטבר. חיבור ל־`observeDocumentReadInvalidation` מרענן גם אחרי פקודת סגנון
שאינה שולחת `onUpdate`. בכל רגע יש קריאה אחת ובקשה ממתינה אחת לחלון האחרון.
כיבוי ופירוק מבטלים תוצאות, המשך בין דפי קריאה, timers ומנויי מדידה.

## אימות

```sh
npm test -- tests/unit/navigation-pane.test.ts tests/unit/navigation-pane-component.test.ts tests/unit/formatting-marks-window.test.ts tests/unit/formatting-marks-layer.test.ts tests/unit/page-ruler.test.ts tests/unit/engine-boundaries.test.ts --maxWorkers=1
npm run build
node scripts/qa/navigation-readout-qa.mjs
```

הגשש בונה מסמך בן 127 בלוקים: metadata אחד + בקשת טקסט לשתי כותרות;
קריאה חוזרת אינה מבקשת שוב את המסמך. הוא מאמת גם גלילה אמיתית לסוף פסקה
חוצה עמוד, את ¶ בממשק ואת כיבוים. ספירות הבקשות הן של הקוראים הנבדקים,
לא של כל ה־RPC הפנימיים במנוע. אין כאן מדידת latency של אוצריא Release.
