# שולחן העורך — מפת פערים מלאה מול שתי התבניות

מיפוי של `שולחן העורך.dotm` (37 מודולים, גירסה 4.0) ו-`שולחן העורך - עיצוב פיסקה.dotm`
(17 מודולים) מול `main` נכון ל-3.9.2026. לכל כלי: האם נכנס, מה חסר, מה נדרש כדי
להכניסו, ובאיזו שכבה נכון להכניס אותו.

מקרא שכבות: **ריפו** = שינוי מקומי ב-`src/`; **מאקרוס** = חבילת `superdoc-macros`
(palmoni5); **אוצריא** = המארח ב-Flutter; **מנוע** = SuperDoc, רק דרך PR upstream.

הערה תפעולית: `node_modules` המקומי מחזיק superdoc 2.10.0 ו-superdoc-macros 0.7.1,
בעוד `package.json` דורש 2.11.0 ו-0.9.0 (הקוד כבר צורך `registerTool` ו-
`extractVbaFromDocx` של 0.9.0). להריץ `npm ci` לפני build או typecheck.

## ג. סיכום לפי שכבה

### ריפו — אפשר עכשיו, בלי לחכות לאף אחד
1. `FixHebrewPunctuation` („תיקון העתקה מתוכנות”) ככלי חדש + כפתור.
2. מרכאות מסולסלות ב-Typos; סט תווים ב„טקסט מתחלף”.
3. „כל המסמך כאחד” בסוגריים לא סגורים.
4. תחום הבחירה ב„הערות ⟵ סוגריים”.
5. אחידות טורים: `count===2` בלבד, בלי דריסת `count`.
6. מילה ראשונה: דילוג על ממורכזות, סינון לפי סגנונות, מאפייני גופן נוספים, שם נכון למצב `fixed`.
7. **מתאם „החל/הסר עיצובים”** בסדר קבוע + התקדמות/עצירה.
8. **זכירת הגדרות** לכל הדיאלוגים: `loadSetting` גנרי ב-`settings.ts` + קומפוזבל `useRememberedDialog`.
9. **צמצום מסמך** (ספירת עמודים מ-`data-page-index` אחרי settle).
10. **סימון עמודים** כ-overlay + snapshot ב-`storage`.
11. **סימני חיתוך** כאפשרות הדפסה/PDF.
12. **פירוק מסמך — הערות שוליים** לטאב חדש + „שמור בשם”.
13. **יישור טורים במקטע הנוכחי** כקירוב חד-פעמי (מדוד ⟵ מכפיל ⟵ כתוב ⟵ אמת).
14. **עיצוב חלון + איזון שורה אחרונה** כקירוב probe-DOM, בכפוף למדידה שאפשר להזריק `<w:br/>` דרך `replace`.
15. החלפת סגנון פסקה⟵פסקה בלולאת `linked-style` (N צעדי undo).

### חבילת המאקרוס (superdoc-macros)
- לוגיקת „שכפל/הסר לפי altText לכל פסקאות סגנון X” לעיטורים, ברגע ש-`create.image` פעיל.
- אריזת האלגוריתמים (חלון, איזון, יישור) לשימוש חוזר אחרי שיהיה layout API.
- חשיפת יכולות לסקריפטי משתמש: `MacroApi` היום = טקסט ופקודות בחירה בלבד (אין `format` לפי טווח, אין הערות, אין `blocks`, אין `storage`). אם רוצים שעורך יכתוב כלים משלו — להוסיף `api.formatRange`, `api.insertFootnote`, `api.blocks`, `api.storage` ב-`MacroHost`/`MacroApi`/`SANDBOX_BOOTSTRAP`.
- אחסון: `MacroStorage` היום על localStorage; מימוש מעל `storage.*` של אוצריא נשמר בין מכונות.

### אוצריא
- כל הצרכים כבר מכוסים: `storage.*` להגדרות, `fs.pickUserFile` לתמונות, „שמור בשם” דרך `commitUserFileWrite` בלי `targetToken`, `ui.exportPdf` שמקבל `pageSize`.
- אין צורך בשינוי Flutter לאף כלי ברשימה. (חסרים כלליים שאינם נחוצים כאן: סריקת תיקייה, זהות משתמש, חלון תוסף נוסף, דיאלוג מארח עם קלט טקסט.)
